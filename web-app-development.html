Questions before you start.

Clear answers help define the right scope.

Do you build mobile apps?

Our service here is browser-based web application development. A responsive web application can work on mobile screens; this is not a claim of native Android or iOS app development.

What do you need to prepare a quote?

A description of the current workflow, users and roles, must-have features, existing data and required integrations. A short initial discussion helps identify what belongs in the first version.

How do you approach testing?

Testing requirements and acceptance criteria are agreed alongside the scope, including the important user journeys and business rules. The exact approach depends on the application.

Can the application connect to existing systems?

We assess the required connection, data access and technical feasibility during discovery. An integration is included only after its scope and provider requirements are confirmed.

Who owns the website and code?

Ownership, access, handover and any third-party licences need to be set out in the project agreement. We discuss these details before development rather than assume the same arrangement fits every project.

What happens after launch?

Maintenance, hosting, updates and support can be scoped alongside the build. Their inclusions, recurring fees and responsibilities should be agreed in writing.
